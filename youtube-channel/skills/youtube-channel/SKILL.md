# Ведение YouTube-канала

## 1. Профиль канала — всегда начинай с него

Перед любой творческой работой прочитай `CHANNEL.md` в корне текущего проекта.
Если файла нет — коротко спроси у пользователя и создай его по шаблону:

```markdown
# Профиль канала
- Название / ссылка:
- Ниша и тема:
- Целевая аудитория (кто, возраст, уровень, боль):
- Язык видео:
- Формат: длинные / Shorts / оба; типичная длина:
- Тон и стиль подачи:
- Частота публикаций:
- Цель на ближайшие 3 месяца (подписчики, просмотры, монетизация):
- Конкуренты и референсы:
- Табу (что не делаем):
```

Все идеи, сценарии и тексты подгоняй под этот профиль. После анализа аналитики
дописывай короткие выводы в раздел `## Что работает` в конце `CHANNEL.md`.

## 2. Структура рабочих файлов в проекте

```
CHANNEL.md                 профиль канала + выводы
ideas.md                   бэклог идей (таблица: идея, хук, оценка, статус)
videos/<YYYY-MM-DD>-<slug>/
    script.md              сценарий
    meta.md                название, описание, теги, таймкоды, текст превью
    upload.json            итог загрузки (id, url, дата)
reports/<YYYY-MM-DD>.md    отчёты аналитики
```

## 3. YouTube API — скрипт `${CLAUDE_PLUGIN_ROOT}/scripts/yt.py`

Все команды выводят JSON. Запуск: `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/yt.py" <команда>`.

| Команда | Что делает |
|---|---|
| `auth` | разовая OAuth-авторизация (откроет браузер) |
| `channel` | подписчики, просмотры, кол-во видео |
| `videos --limit 20` | последние видео со статистикой |
| `analytics --days 28` | итоги, источники трафика, данные по дням |
| `top --days 28 --limit 10` | топ видео за период |
| `video-stats ID --days 90` | метрики и кривая удержания одного видео |
| `comments [--video ID] [--unanswered] --limit 50` | комментарии |
| `reply COMMENT_ID --text "..." --yes` | ответить на комментарий |
| `upload FILE --title ... [--yes]` | загрузка видео (без `--yes` — пробный прогон) |

На Windows запускай `python` вместо `python3`, если `python3` не найден.

Если скрипт вернул `{"error": ...}` с `hint` — выполни подсказку или передай её
пользователю. При ошибке «Нет авторизации» направь к `/yt-setup`.

## 4. Правила безопасности (обязательно)

- **Никогда** не публикуй ничего без явного «да» от пользователя в этом разговоре:
  загрузка видео и ответы на комментарии видны публично.
- Загрузка: сначала запусти `upload` без `--yes`, покажи метаданные, дождись
  подтверждения, потом повтори с `--yes`. По умолчанию — `private`, если
  пользователь не попросил иначе.
- Ответы на комментарии: покажи все черновики списком, отправляй только
  одобренные. Не отвечай на спам, оскорбления и провокации — предложи их
  пропустить или скрыть вручную в Studio.
- Квота API — 10 000 единиц в день; одна загрузка ≈ 1600. Не гоняй лишние запросы.
- Не трогай `~/.config/yt-claude/token.json` и не выводи его содержимое.

## 5. Ремесло: как делать хорошо

**Идеи.** Каждая идея = конкретное обещание зрителю. Оценивай по 1–5:
спрос (ищут ли это), соответствие нише, «кликабельность» (можно ли сделать
сильное название + превью), сложность производства. Опирайся на топ видео
канала из аналитики, если она доступна.

**Названия.** До ~60 символов видно целиком. Конкретика, цифры, интрига
без кликбейта, ключевое слово ближе к началу. Давай 5–7 вариантов разных типов
(вопрос, результат, ошибка, сравнение, история) и отметь фаворита.

**Превью.** Название и превью работают в паре: текст на превью (2–4 слова)
не повторяет название, а дополняет. Опиши композицию: эмоция, объект, контраст.

**Сценарий длинного видео.**
1. Хук (0–15 с): сразу обещание / результат / конфликт, без приветствий.
2. Подтверждение ожиданий (15–45 с): почему стоит досмотреть.
3. Основная часть блоками, в каждом — мини-хук перед переходом («но тут
   есть подвох…»), чтобы не было провалов удержания.
4. Кульминация / главный инсайт ближе к 70–80 % хронометража.
5. Концовка: короткий вывод + переход на следующее видео (end screen),
   без длинных прощаний.
Пиши разговорным языком, с пометками `[B-ROLL: ...]`, `[ГРАФИКА: ...]`,
`[ПЕРЕБИВКА]`. Указывай примерный хронометраж блоков (≈150 слов в минуту).

**Shorts.** До 60 с, хук в первые 1–2 секунды, одна мысль, петля в конце
(последняя фраза подводит к началу).

**Описание.** Первые 1–2 строки — суть с ключевыми словами (видны до «ещё»).
Дальше: подробности, таймкоды (с 00:00, минимум 3, каждый ≥10 с), ссылки,
3 хэштега максимум в конце. Теги: 5–15, от точных к широким, ≤500 символов суммарно.

## 6. AI-шортсы (команда /yt-short)

Сборка: `python "${CLAUDE_PLUGIN_ROOT}/scripts/short.py" build <папка>/short.json`
(формат short.json описан в начале short.py). Голоса: `ru-RU-DmitryNeural` (мужской),
`ru-RU-SvetlanaNeural` (женский); скорость `+8%…+15%`. Категория для загрузки игр — `--category 20`.

**Сценарий шортса (90–130 слов, 30–50 с):**
1. Хук ≤ 8 слов, сразу интрига: «В GTA 5 есть место, куда никто не доходит».
2. 3–5 коротких сегментов, по 1–2 предложения, каждый — отдельный факт/шаг.
3. Последняя фраза закольцовывает с началом или зовёт на часть 2. Без «всем привет» и «ставьте лайк» в начале.
4. Пиши для уха: короткие фразы, числа словами, если edge-tts читает их криво («две тысячи тринадцатом»).
5. Одна мысль на ролик. Каждый сегмент — смена картинки (≈3–6 с).

**Картинка.** Лучше всего — свои записи геймплея в папке `clips/` (OBS / Xbox Game Bar Win+Alt+R).
Pexels даёт только общие «игровые» кадры (клавиатуры, геймпады, неон) — подходят для связок.
Не бери трейлеры, кат-сцены и чужие видео целиком: Content ID и страйки.

**Чтобы канал не попал под «inauthentic content» (с июля 2026 YouTube не монетизирует шаблонный AI-контент):**
- каждый ролик — проверенные конкретные факты, а не вода; свой взгляд и выводы;
- варьируй форматы (факты, топ‑3, «почему…», сравнение, разбор механики), не клонируй один шаблон;
- лучше свой геймплей, чем стоки; пользователь просматривает каждый ролик перед загрузкой;
- никаких фейковых «экспертов», выдуманных новостей и сливов;
- реалистичные сгенерированные люди/события → флаг `--synthetic` при загрузке.

**Форматы для игрового канала:** пасхалки и секреты; «факт, который знают 1 %»; история создания
игры; вырезанный контент; топ‑3 (оружие, боссы, локации); «почему X такой сложный»; новости и даты
выходов (только с источниками); советы новичкам по конкретной игре.

## 7. Аналитика

**Аналитика — что смотреть.**
- CTR превью низкий + показы высокие → менять название/превью.
- Средний % просмотра < 30–35 % у длинных видео → проблема хука или затянутость;
  смотри кривую удержания (`video-stats`), где резкие падения.
- Источники трафика: рост «Browse/Suggested» = алгоритм подхватил; доминирует
  «Search» = делай больше поисковых тем.
- Всегда заканчивай отчёт 3 конкретными действиями на следующую неделю.
