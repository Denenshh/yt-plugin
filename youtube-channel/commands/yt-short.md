Сделай шортс (или серию) по скиллу youtube-channel, раздел «AI-шортсы». Задание: $ARGUMENTS

1. Прочитай `CHANNEL.md`. Если темы нет — возьми лучшую из `ideas.md` или предложи 3 и выбери самую сильную.
2. **Проверь факты** веб-поиском (минимум 2 источника на каждый факт). Неподтверждённое — выкинь.
   Источники запиши в `videos/<дата>-<slug>/sources.md`.
3. Напиши сценарий 90–130 слов (30–50 с) по правилам скилла и сохрани
   `videos/<дата>-<slug>/short.json`. Для каждого сегмента подбери картинку:
   свой клип из `clips/` (если есть подходящий), иначе `visual` — запрос к Pexels на английском.
4. Проверь окружение: `python "${CLAUDE_PLUGIN_ROOT}/scripts/short.py" check`. Если чего-то нет —
   покажи подсказки и предложи установить.
5. Собери: `python "${CLAUDE_PLUGIN_ROOT}/scripts/short.py" build videos/<...>/short.json`.
6. Подготовь `meta.md`: название (≤60 символов, с названием игры), описание 2–3 строки +
   `#shorts` и 1–2 хэштега, 5–10 тегов.
7. Покажи пользователю: путь к `short.mp4`, текст сценария, название. Попроси открыть и посмотреть видео.
8. **Только после «ок»** загрузи через `yt.py upload ... --yes` (privacy и время публикации — как скажет
   пользователь; по умолчанию private). Если в ролике реалистичные сгенерированные люди/события — добавь `--synthetic`.
9. Отметь идею в `ideas.md` как «опубликовано», сохрани `upload.json`.

Если попросили серию — делай по одному: собери все, покажи список, загружай пачкой только после одобрения,
с расписанием (например, раз в день в 18:00 по Москве).
