Напиши сценарий по скиллу youtube-channel. Задание: $ARGUMENTS

1. Прочитай `CHANNEL.md` (тон, аудитория, язык).
2. Если тема требует фактов — проверь их через поиск и отметь источники в конце.
3. Предложи 3 варианта хука, выбери лучший.
4. Напиши сценарий по структуре из скилла, с хронометражем блоков и пометками
   B-ROLL / ГРАФИКА.
5. Сохрани в `videos/<YYYY-MM-DD>-<slug>/script.md` и кратко сообщи итог:
   длительность, ключевая идея, что снять дополнительно.
