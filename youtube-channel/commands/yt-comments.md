Разбери комментарии по скиллу youtube-channel. Аргументы: $ARGUMENTS

1. Прочитай `CHANNEL.md` (тон общения).
2. Получи `comments --unanswered --limit N` (и `--video ID`, если указан).
3. Сгруппируй: вопросы, благодарности, критика, идеи для видео, спам/токсичность.
4. Для каждого (кроме спама) предложи короткий живой ответ в тоне канала.
   Покажи пронумерованный список: автор — комментарий — черновик ответа.
5. Спроси, какие отправить (например «все», «1,3,5» или с правками).
6. Отправь только одобренные: `reply <comment_id> --text "..." --yes`.
7. Идеи для видео из комментариев предложи добавить в `ideas.md`.
